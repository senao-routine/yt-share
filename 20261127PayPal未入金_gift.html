未入金の朝まとめキット

PayPal を開いて請求書の一覧を目で追い、期日と照らして催促の文を毎回書く（数本でも 10〜15 分・忘れると期限切れに気づくのが週単位で遅れる）→ 毎朝決まった時刻に 1 枚と通知が来て、期限切れの分の催促の下書きまでできている（自分は直して送るだけ）。【実測待ち】自分の PayPal での前後の時間

非エンジニアの業務（画面版）・開発者（ターミナル・Claude Code） 向け
未入金の朝まとめキット.zip をダウンロード

11 ファイル・588 KB。スマホで開いたときは、パソコンで開き直してからダウンロードしてください。

PayPal で送った請求書を 見るだけ で読み、毎朝 1 枚にまとめます。

  • 期限切れ・今日が期限・もうすぐ期限・この数日の入金を、件数と合計で出します
  • 期限切れの分だけ、催促メールの 下書き を作ります（送るのは自分）
  • 送る・催促・取り消し・入金の記録・送金・返金は しません（コードに道がありません）

鍵が無くても、架空の請求書 11 本（見本）ですぐ試せます。

画面に映す・人に見せるときは、相手の名前とメールを伏せます。

自分の PayPal につなぐ

  1. PayPal の開発者の画面（developer.paypal.com）にビジネスアカウントでログインし、「Apps & Credentials」でアプリを作ります。最初は Sandbox（試し用）で作るのがおすすめです。
  2. 出てきた Client ID と Secret を、この Mac のキーチェーンに入れます。打った文字は画面に出ません。AI のチャットには貼らないでください。
python3 unpaid_watch.py key-set --env sandbox
  1. 鍵が持っている権限の名前を見ます（鍵の中身は出しません）。
python3 unpaid_watch.py key-check --env sandbox
  1. 読んでみます。
python3 unpaid_watch.py --env sandbox

本番に切り替えるときは、本番（Live）のアプリで 2〜4 を --env live でくり返し、設定.json の「つなぐ先」を live にします。

Claude Code で使う

このフォルダで claude を開き、「今朝の未入金を見て」と頼みます。中のスキル（.claude/skills/unpaid-check）が --mask 付きで道具を回し、5 行にまとめ、催促の下書きを整えます。

  • 最初に 1 回だけ、このフォルダで claude を開いたときに出る「このフォルダを信頼しますか」で信頼を選んでください。信頼するまでは、キットの「許可」の設定が効きません（「禁止」の設定は最初から効きます）。
  • 「催促を送って」と頼んでも送りません。下書きの場所と、PayPal の画面で押す場所を案内します。

PayPal 公式の MCP を使う人へ

PayPal 公式の MCP（@paypal/mcp）を使うなら、読む 2 つの道具だけを渡します。

npx -y @paypal/mcp --tools=invoices.list,invoices.get

--tools=all にすると、請求書を作る・送る・催促・取り消しの道具も AI に渡ります。この書式は公開パッケージ（1.8.1）の中身で確かめた物で、PayPal の説明のページには --tools=all の例しか載っていません。MCP に渡す通行証は数時間で切れるので、毎朝の自動実行にはこのキットの形（鍵から毎回もらう）が向いています。

安全の作り（3 重）

  1. 道具の門: PayPal へ出してよいのは「通行証をもらう」と「請求書を読む（GET）」だけ。ほかは送る前に止まります。確かめるには:
python3 unpaid_watch.py guard-check
  1. 鍵の置き場: 鍵はキーチェーン（か環境変数）だけ。ファイル・画面・ログ・まとめに出しません。
  2. Claude Code の禁止の設定（.claude/settings.json）: 鍵を取り出す security・curl・道具や設定の書き換え・PayPal の MCP の書き込みの道具を禁止しています。

PayPal の仕様では、請求書を読むのに要る権限は「読む」（invoices/read）だけで、送る・催促・入金の記録には「書く」（readwrite）が要ります。ただ、アプリの設定で鍵を「読むだけ」に絞れるかは、PayPal の説明には書かれていません。だからこのキットは、鍵が強くても使わない作りにしています。key-check で、自分の鍵にどんな権限が付いているかを見ておいてください。

# 未入金を見る（見るだけ）

このフォルダの `unpaid_watch.py` だけを使う。PayPal へ出せるのは「通行証をもらう」と「請求書を読む」だけで、ほかは道具の門が断る。

## 手順

1. `python3 unpaid_watch.py --mask` を打つ（相手の名前を伏せる。本人が「伏せなくていい」と言ったら `--mask` を外す。鍵がまだ無いときは `--demo` で見本を使い、そう伝える）。
2. `朝のまとめ/<今日の日付>.md` を読み（見本は `<今日の日付>_見本.md`・sandbox は `<今日の日付>_sandbox.md`）、次の形で 5 行以内にまとめる:
   - 期限切れ: 件数と合計（いちばん古い 1 件の番号と日数）
   - 今日が期限・もうすぐ: 件数と合計
   - この数日の入金: 件数
   - 一部だけ入金の物があれば、その番号と残り
3. 催促の下書きは、同じ名前に `_催促の下書き.md` を付けたファイルにある（例 `<今日の日付>_見本_催促の下書き.md`）。頼まれたら文面だけ直して見せる（相手との関係に合わせて丁寧さを変える）。
4. 送るのは本人。どこで送るかを 1 行で案内する（メールで送る・または PayPal の請求書の画面の「リマインダーを送信」）。

## してはいけないこと（頼まれてもしない）

- 請求書を送る・催促を送る・取り消す・消す・支払い済みにする・送金・返金。このキットには口が無い。頼まれたら「このキットは読むだけなので送れません。PayPal の画面で本人が押します」と答えて、押す場所を案内する。
- 鍵を読む・表示する（キーチェーン・環境変数・`security` コマンド）。
- `unpaid_watch.py` や `.claude/` の中を書き換えて、読む以外の道を足す。
- PayPal の公式 MCP の書き込みのツール（create・send・send_invoice_reminder・cancel）を使う。

def has_key(where: str) -> bool:
    """道具（credentials）と同じ条件で鍵がそろっているか＝環境変数の 2 つ、か、キーチェーンの 2 つ（中身は読まない＝ -w を付けない）。"""
    if where == "見本":

        return True

        return False
    for acct in (where + "-client-id", where + "-secret"):
        try:
            r = subprocess.run(["security", "find-generic-password", "-s", "unpaid-watch-paypal", "-a", acct],
                               capture_output=True, text=True, timeout=20)
        except (subprocess.TimeoutExpired, OSError):
            return False
        if r.returncode != 0:
            return False
    return True


def read_nofollow(path: Path) -> bytes | None:
    """リンクをたどらずに開き、開いた物が通常のファイルのときだけ読む（確かめた物と読む物を同じにする）。"""
    import stat as _st
    try:
        dfd = os.open(str(path.parent), os.O_RDONLY | os.O_DIRECTORY | os.O_NOFOLLOW)
    except OSError:
        return None
    try:
        fd = os.open(path.name, os.O_RDONLY | os.O_NOFOLLOW, dir_fd=dfd)
    except OSError:
        os.close(dfd)
        return None
    try:
        if not _st.S_ISREG(os.fstat(fd).st_mode):
            return None
        chunks = []
        while True:
            b = os.read(fd, 1 << 20)
            if not b:
                break
            chunks.append(b)
        return b"".join(chunks)
    finally:
        os.close(fd)
        os.close(dfd)

def last_result() -> dict | None:
    if not OUT.is_dir() or OUT.is_symlink():
        return None
    files = []
    for f in OUT.glob("*.json"):
        if not DAY_RX.match(f.stem) or f.is_symlink():
            continue
        try:
            files.append((f.lstat().st_mtime, f))
        except OSError:
            continue                      # 走っている間に消えた物は読み飛ばす
    for _, f in sorted(files, reverse=True):
        raw = read_nofollow(f)
        if raw is None:
            continue
        try:
            return json.loads(raw.decode("utf-8")).get("result")
        except (UnicodeDecodeError, ValueError):
            continue
    return None


def tok_ok(value) -> bool:
    """合言葉の照合（ASCII でない値は例外にせず、合わない扱い）。"""
    return isinstance(value, str) and value.isascii() and secrets.compare_digest(value.encode(), APP.token.encode())


class Job:
    def __init__(self, args: list[str]):
        self.events: list[dict] = []
        self.done = False
        self.rc = None
        self.started = time.time()
        out = ["--out", str(OUT)] if OUT != KIT / "朝のまとめ" else []
        self.proc = subprocess.Popen([py(), str(TOOL), "--events"] + out + args, cwd=str(KIT), stdout=subprocess.PIPE,
                                     stderr=subprocess.PIPE, text=True, bufsize=1)
        threading.Thread(target=self._read, daemon=True).start()

    def _read(self):
        for line in self.proc.stdout:
            line = line.strip()
            if not line:
                continue
            try:
                self.events.append(json.loads(line))
            except ValueError:
                pass
        err = self.proc.stderr.read()
        self.rc = self.proc.wait()
        if self.rc and not any(e.get("step") == "error" for e in self.events):
            self.events.append({"step": "error", "text": (err.strip().splitlines() or ["うまく動きませんでした"])[-1]})
        self.done = True


class App:
    def __init__(self):
        self.token = secrets.token_urlsafe(18)
        self.port = 0
        self.job: Job | None = None
        self.lock = threading.Lock()

    def start_job(self, where: str, masked: bool) -> tuple[bool, str]:
        if where not in WHERE:
            return False, "つなぐ先が違います"
        with self.lock:
            if self.job and not self.job.done:
                if time.time() - self.job.started < LIMIT_SEC:
                    return False, "いま読んでいる途中です"
                self.job.proc.kill()
            args = list(WHERE[where]) + (["--mask"] if masked else [])
            self.job = Job(args)
        return True, ""

class Handler(http.server.BaseHTTPRequestHandler):
    server_version = "unpaid-watch"

    def log_message(self, *a):
        pass

    # ── 門 ──
    def _host_ok(self) -> bool:
        return self.headers.get("Host", "") in ("127.0.0.1:%d" % APP.port, "localhost:%d" % APP.port)

    def _token_ok(self) -> bool:
        return tok_ok(self.headers.get("X-Kit-Token", ""))

    def _send(self, code: int, body, ctype="application/json; charset=utf-8"):
        raw = body if isinstance(body, bytes) else (json.dumps(body, ensure_ascii=False).encode() if not isinstance(body, str) else body.encode())
        self.send_response(code)
        self.send_header("Content-Type", ctype)
        self.send_header("Content-Length", str(len(raw)))
        self.send_header("Cache-Control", "no-store")
        self.send_header("X-Content-Type-Options", "nosniff")
        self.send_header("Content-Security-Policy", "default-src 'self'; style-src 'self' 'unsafe-inline'; script-src 'self' 'unsafe-inline'; img-src 'self' data:")
        self.end_headers()
        self.wfile.write(raw)

    def do_GET(self):
        if not self._host_ok():
            return self._send(403, {"error": "host"})
        u = urllib.parse.urlparse(self.path)
        q = urllib.parse.parse_qs(u.query)
        if u.path == "/":
            if not tok_ok((q.get("t") or [""])[0]):
                return self._send(403, "合言葉の付いた URL から開いてください（画面で使う.command が開きます）", "text/plain; charset=utf-8")
            page = (UI / "index.html").read_text(encoding="utf-8")
            return self._send(200, page, "text/html; charset=utf-8")
        if u.path.startswith("/report/"):
            day = u.path[len("/report/"):]
            day = urllib.parse.unquote(day)
            if not (DAY_RX.match(day) and tok_ok((q.get("t") or [""])[0])):
                return self._send(403, {"error": "report"})
            raw = None if OUT.is_symlink() else read_nofollow(OUT / (day + ".html"))
            return self._send(200, raw, "text/html; charset=utf-8") if raw is not None else self._send(404, {"error": "none"})
        if not self._token_ok():
            return self._send(403, {"error": "token"})
        if u.path == "/api/state":
            w = settings_where()
            return self._send(200, {"where": w, "keys": {k: has_key(k) for k in WHERE}, "last": last_result()})
        if u.path == "/api/job":
            raw = (q.get("since") or ["0"])[0] or "0"
            if not NUM_RX.match(raw):
                return self._send(400, {"error": "since"})
            since = int(raw)
            j = APP.job
            if not j:
                return self._send(200, {"events": [], "done": True, "rc": None})
            return self._send(200, {"events": j.events[since:], "next": len(j.events), "done": j.done, "rc": j.rc,
                                    "elapsed": round(time.time() - j.started, 1)})
        return self._send(404, {"error": "none"})

    def do_POST(self):
        if not self._host_ok() or not self._token_ok():
            return self._send(403, {"error": "token"})
        if not (self.headers.get("Content-Type") or "").startswith("application/json"):
            return self._send(415, {"error": "json"})
        raw_len = (self.headers.get("Content-Length") or "0").strip()
        if not NUM_RX.match(raw_len):
            return self._send(400, {"error": "length"})
        n = int(raw_len)
        if n > BODY_MAX:
            return self._send(413, {"error": "big"})
        try:
            body = json.loads(self.rfile.read(n) or b"{}")
        except ValueError:
            return self._send(400, {"error": "json"})
        if not isinstance(body, dict):
            return self._send(400, {"error": "json"})
        path = urllib.parse.urlparse(self.path).path
        if path == "/api/run":
            ok, why = APP.start_job(str(body.get("where") or ""), bool(body.get("mask")))
            return self._send(200 if ok else 409, {"ok": ok, "why": why})
        if path == "/api/guard":
            r = subprocess.run([py(), str(TOOL), "guard-check", "--json"], cwd=str(KIT), capture_output=True, text=True, timeout=30)
            try:
                return self._send(200, json.loads(r.stdout))
            except ValueError:
                return self._send(500, {"error": "guard"})
        return self._send(404, {"error": "none"})

    do_PUT = do_DELETE = do_PATCH = lambda self: self._send(405, {"error": "読むだけの画面です"})

#!/bin/bash
# 未入金の朝まとめを、毎朝 決まった時刻に自動で作る（Mac の launchd）。
#   bash 毎朝に入れる.sh            毎朝 8:30 に入れる
#   bash 毎朝に入れる.sh 7:45       時刻を変えて入れる
#   bash 毎朝に入れる.sh --remove   やめる
# 作るだけです（送る・催促はしません）。できたら Mac の通知が出て、朝のまとめ/ に 1 枚できます。
set -euo pipefail
KIT="$(cd "$(dirname "$0")" && pwd)"
LABEL="com.unpaid-watch.morning"
PLIST="$HOME/Library/LaunchAgents/$LABEL.plist"
if [ "${1:-}" = "--remove" ]; then
  launchctl bootout "gui/$(id -u)/$LABEL" 2>/dev/null || true
  rm -f "$PLIST"
  echo "✓ 毎朝の自動実行をやめました"
  exit 0
fi
AT="${1:-8:30}"
H="${AT%%:*}"; M="${AT##*:}"
case "$H$M" in (*[!0-9]*|'') echo "時刻は 8:30 の形で書いてください"; exit 2;; esac
if [ "$((10#$H))" -gt 23 ] || [ "$((10#$M))" -gt 59 ]; then echo "時刻は 0:00〜23:59 で書いてください"; exit 2; fi
mkdir -p "$HOME/Library/LaunchAgents" "$KIT/朝のまとめ"
cat > "$PLIST" <<PL
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
<plist version="1.0"><dict>
  <key>Label</key><string>$LABEL</string>
  <key>ProgramArguments</key><array>
    <string>/usr/bin/python3</string><string>$KIT/unpaid_watch.py</string><string>--notify</string><string>--quiet</string>
  </array>
  <key>WorkingDirectory</key><string>$KIT</string>
  <key>StartCalendarInterval</key><dict><key>Hour</key><integer>$((10#$H))</integer><key>Minute</key><integer>$((10#$M))</integer></dict>
  <key>StandardOutPath</key><string>$KIT/朝のまとめ/_自動実行の記録.txt</string>
  <key>StandardErrorPath</key><string>$KIT/朝のまとめ/_自動実行の記録.txt</string>
</dict></plist>
PL
launchctl bootout "gui/$(id -u)/$LABEL" 2>/dev/null || true
launchctl bootstrap "gui/$(id -u)" "$PLIST"
echo "✓ 毎朝 $AT に作ります（つなぐ先は 設定.json の「つなぐ先」）。やめるとき: bash 毎朝に入れる.sh --remove"
