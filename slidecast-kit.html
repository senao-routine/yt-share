スライドキャストキット
— キャラが喋る解説動画メーカー

台本ファイルを1枚書いて1コマンド実行すると、2Dキャラクターが口パクで喋る解説動画（フルHD mp4）ができあがります。毎朝X（旧Twitter）に自動投稿している5分のAIニュース動画と、同じ仕組みの配布版です。

OVERVIEW仕組み（台本→動画まで全自動）

  • 2つの形式 — 2キャラ掛け合いのpodcast形式（ニュース・対談向き）と、1キャラ解説のsolo形式（チュートリアル向き）
  • visual文法 — 棒グラフ・大数値・スペック表・循環図・フロー図・Webスクショ・台詞同期カードを台本から指定
  • ポーズ切替 — 指差し・考え中・手上げを台詞1行ごとに指定可能
  • 直しに強い — 台本を1行直すと、その行の音声だけ再生成（キャッシュ内蔵でコスト最小）

SETUPセットアップの流れ（約15分＋ダウンロード時間）

  1. zipを展開し、Claude Code でフォルダを開く
  2. /slidecast-setup を実行 → 環境チェックから順に案内されます
  3. 合格判定（verify_format）が2形式とも「失敗 0」になればOK
  4. Fish AudioのAPIキーを .env に設定
  5. run_job.py でサンプル台本を実行 → 最初の1本（48秒）が完成
