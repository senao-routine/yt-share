AI検証ダッシュボード

同じお題を最大4つの AI に同時に出して、出来上がりを横に並べて見くらべる道具です。 かかった時間・トークン数（AI が読み書きする量の単位）・費用も、数字で横に並びます。 終わった結果は「記録（自分の検証表）」に1行ずつ自動でたまります。新しいモデルが出たら、同じお題を流すだけで、自分の表に1行増えて歴代と比べられます。

要るもの

  • ブラウザ（Chrome・Edge・Safari など）。入れる物（インストール）はありません。
  • OpenRouter（いろいろな会社の AI を、1つの窓口で使えるサービス）の鍵
  • 鍵で AI を使うには、OpenRouter に前もって少し入金しておく必要があります。最低いくらから入金できるかは、OpenRouter の画面で確かめてください。

使い方（3手）

  1. OpenRouter で鍵を作る：https://openrouter.ai/keys を開き、鍵を作ります。鍵は sk-or- で始まる長い文字の列です。
  2. ダッシュボードを開いて鍵を貼る：このフォルダの キット.html をダブルクリックで開き、いちばん上の「OpenRouter の鍵」の欄に貼ります。
  3. お題を選んで走らせる：お題の見本のボタンを1つ押し（自分で書いてもかまいません）、「全部同時に走らせる」を押します。初めての1回は、答えが短い「お試し：短い3問で速さと正しさ」が早く安く終わります。

最初から、A に Qwen4 Max、B に Claude Fable 5.2、C に Gemini 4 Carbon、D に GPT-6.1 Sol が入っています。モデルの欄に「qwen」「claude」「gemini」「gpt」「kimi」などと打つと候補が出て、ほかのモデルにも替えられます。「列の数」で 2〜4 列を選べます。替えた列とモデルは、このブラウザが覚えています（「最初のモデルに戻す」で元に戻ります）。

走っている間に見えるもの

  • 段：送信 → 考え中 → 書いている → 完了 の、いまどこかが列ごとに出ます。
  • 光の帯：列のいちばん上の細い帯が、走っている間は動き続けます。
  • 数字：経過の秒・書き始めるまでの秒・出力のトークン（途中は目安・終わると OpenRouter の実数）・1秒あたりの量が、その場で増えていきます。

待ち時間を長く見せる仕掛けは入れていません。数字は実際にかかった分です。

終わったら

  • プレビュー：画面（HTML）を作らせたお題なら、作られた画面がそのまま動きます。文章のお題なら、本文が読みやすく出ます。
  • 中身：作られたコードや文章そのものです。「保存」でファイルに、「コピー」で手元に写せます。
  • 数字で比べる：かかった秒・書き始めるまで・トークン・1秒あたりの量・費用が横に並びます。いちばん速い・安い・トークンが少ない列には印が付きます。
  • 比べた結果を1枚に保存：お題・数字・全部の列の出来上がりを、1つの HTML ファイルにまとめて保存します。あとで見返したり、人に渡したりできます（鍵は入りません）。
  • この列だけ：各列の右上のボタンで、その列だけを走らせ直せます。

設定（変えなくても使えます）

  • 最大出力トークン：答えの長さの上限です。最初は 32000。費用の上限もこれで決まります。考える AI は、答える前に考えた分もこの上限に数えられます。画面を作らせるお題で「最大出力で切れました」と出たら、上げて走らせ直してください（試したときは 16,000 だと考える分で埋まって切れました）。
  • 考える深さ：答える前にどのくらい考えさせるか。列ごとに選べて、そのモデルが受け付ける段だけが出ます。「指定なし」はモデルにまかせます。深いほど時間と費用がかかります。
  • 為替：円の金額を出すときの「1ドル＝何円」。最初は 150 円で、目安です。

記録（自分の検証表）の使い方

走らせて終わった列は、上の「記録（自分の検証表）」のタブに、自動で1行ずつ入ります。止めた列・うまくいかなかった列は入りません。

  • 入るもの：日時・お題の名前・お題の指紋・列・モデル・考える深さ・かかった秒・書き始めるまでの秒・入力／出力／考えたトークン・1秒あたりの量・費用（OpenRouter の「実額」か、単価から出した「計算値」か）・終わり方。
  • 入らないもの：鍵と、作られた画面や文章の本文（記録が重くなるため）。出来上がりを残したいときは「比べた結果を1枚に保存」を使ってください。
  • お題の指紋：お題の文から作る短い英数字です。同じ文（と同じ画像）なら同じ指紋になるので、「同じお題で比べた記録」をまとめられます。1文字でも変えると別の指紋になります。
  • お題の名前：見本を選ぶと見本の名前が入ります。自分のお題のときは、好きな名前を付けられます（空のときは、お題の書き出しを使います）。

判定とメモ

各行に、自分の判定（◯ よい／△ まあまあ／✕ だめ）と、ひとことメモを付けられます。結果の列の下でも、記録の表でも付けられて、押したその場で記録に残ります。同じ印をもう一度押すと外れます。

3つの見方

  • 1回ずつ：新しい順に1行ずつ。判定とメモはここで付けます。
  • モデル別：モデルごとの回数・平均の時間・平均の書き始め・平均の1秒あたり・平均の費用・◯の割合。お題がまちまちだと平均は比べにくいので、同じお題で比べるときは「お題別」を見てください。
  • お題別：同じ指紋のお題ごとに、走らせた順にモデルが並びます（歴代の記録）。その中でいちばん速い・安い行に印が付きます。

書き出し・読み込み・消す

  • JSON で書き出す：記録をまるごと1つのファイルに保存します。ブラウザを替えるとき・記録を守りたいときに使います。
  • JSON を読み込む：書き出したファイルを読み込みます。同じ記録（指紋・日時・モデル・列が同じ）は足さないので、同じファイルを何度読み込んでも増えません。
  • CSV で書き出す：表計算ソフト（Excel・Google スプレッドシートなど）で開ける形で保存します。
  • 全部消す：画面の中に「○件を全部消しますか？」と出るので、もう一度押すと消えます。元に戻せないので、先に JSON で書き出しておくと安心です。

記録の置き場について

記録は、このブラウザの中（localStorage という置き場）に残ります。次の点に気をつけてください。

  • ブラウザの「閲覧履歴やサイトのデータを消す」をすると、記録も消えます。ときどき JSON で書き出してください。
  • 別のブラウザ・別のパソコンには引き継がれません。書き出したファイルを読み込んで移します。
  • プライベートブラウズなど、置き場が使えないときは「このブラウザでは記録を残せません。書き出しで保存してください。」と出ます。そのときも画面を閉じるまでは記録・判定・書き出しは使えます。

費用の考え方

  • 費用 ＝ 使ったトークン数 × 単価 です。単価はモデルごとに違い、「100万トークンあたり何ドル」で決まっています。読んだ分（入力）と書いた分（出力）で単価が違います。
  • 単価は、画面を開くたびに OpenRouter の一覧から読み込んで出します。この道具の中に値段は書いていません。
  • 「全部同時に走らせる」ボタンのそばに、列ごとと合計で「この1回で最大いくらかかるか」の目安（最大出力トークン × 出力単価）が出ます。最後まで書き切れば、ふつうはこれより少なく済みます。上限まで書いて切れたときは、お題を読む分（入力）が少し足されて、目安をわずかに超えることがあります。4列で走らせると、目安も4つぶん足されます。
  • 終わると、OpenRouter が返した実際の費用（実額）を出します。返ってこないときは、単価 × トークンで計算した値を「計算値」として出します。
  • 途中で「止める」を押しても、それまでに作られた分は費用がかかることがあります。
  • 画像を添えると、画像の分も入力として数えられます。

鍵の扱い

  • 鍵は、開いているタブの中だけに置きます。タブを閉じると消えます。「鍵を消す」ボタンで、すぐ消すこともできます。
  • 鍵を送る先は openrouter.ai だけです。ほかの場所には送りません。
  • 鍵は、記録にも、JSON・CSV の書き出しにも、「比べた結果を1枚に保存」のファイルにも入りません。メモ欄に鍵のような文字を書いても、記録には残しません。
  • AI が作った画面（プレビュー）は、鍵にも記録にもこの画面にも触れられない囲いの中で動きます。プレビューの中に鍵を打ち込まないでください。
  • 作られた画面が、外の部品（3D やグラフの部品など）をネットから読み込むことがあります。鍵は囲いの外に置いてあるので、その部品には届きません。
  • 画面を人に見せる・録画するときは、鍵の欄を「隠す」にしておくか、鍵を消してからにしてください。
  • 鍵を人に見られたかもしれないときは、OpenRouter の鍵の画面でその鍵を消して、作り直してください。

画像を添える

お題の欄の右（スマホでは下）にある「画像を1枚添える」で、画像を1枚だけ添えられます。添えると、全部の列の AI に同じ画像を見せて比べられます。

  • 添え方：「画像を選ぶ」を押して選ぶか、画像をこの画面に引きずって置きます。png・jpg・webp で、5MB までです。やめるときは「取り外す」を押します。
  • 画像は送るときに読むだけで、どこにも保存しません（記録には画像の名前だけが残ります）。
  • 見本の間取り図で試す：「間取り図の画像 → 歩ける3Dの家」のボタンを押し、このフォルダの 見本の間取り図.png（架空の家の図面）を添えて、「全部同時に走らせる」を押します。長い答えになるお題なので、最大出力トークンが 65,536 に上がります（費用の上限の目安も上がります）。
  • 画像を読めないモデルもあります：画像を読めないモデルの列は走らずに案内が出ます（ほかの列は走ります）。モデルの欄の下の「読めるもの」に「画像」があるモデルを選んでください。
  • 作られた 3D の画面は、3D の部品をネットから読み込んで動きます。ネットにつながっていないと表示されません。
  • 住所や名前など、個人の情報が入った画像は送らないでください。 画像は OpenRouter を通して、AI の会社へ送られます。

通信が止まるとき（ダブルクリックで開くと動かないブラウザ）

ブラウザによっては、ダブルクリックで開いたファイルからの通信を止めることがあります。そのときは、このフォルダで小さなサーバー（ファイルを渡すだけの仕組み）を動かして開きます。

python3 -m http.server 8000

Mac なら「ターミナル」を開き、cd と打ってから（cd の後ろに空白を1つ）、このフォルダをターミナルの窓に引きずって入れて Enter。続けて上の1行を打って Enter。ブラウザで http://localhost:8000/ を開き、キット.html を選びます。終わるときは、ターミナルで Control キーを押しながら C を押します。Windows では py -m http.server 8000 を使います。

サーバーで開くと、ブラウザから見ると「別の場所」になるので、ダブルクリックで開いていたときの記録は見えません。ダブルクリックの側で JSON を書き出し、サーバーの側で読み込んでください。

自分のお題を足すには

  1. キット.html をテキストエディター（メモ帳など）で開きます。
  2. id="presets" と書かれた所を探します。中は [ … ] で囲まれたお題の並び（配列）です。
  3. いちばん最後の } の後ろに , を付けて、次の形で1つ足し、保存します。
{
  "id": "my_first",
  "title": "ボタンに出る名前",
  "kind": "html",
  "note": "ボタンの下に出る説明",
  "body": "1行目のお題。\n2行目のお題。"
}
  • kind は、画面（HTML）を作らせるお題なら "html"、文章を書かせるお題なら "text" です。
  • body の中の改行は \n と書きます。
  • 要るときだけ足せるもの："needs_image": true（画像を1枚添えて使うお題にする）、"image_hint": "…"（画像が無いときの案内）、"suggest_max_tokens": 65536（選んだとき最大出力トークンをこの値まで上げる）。
  • 書き方を間違えると、画面に「お題の見本（presets）の書き方に誤りがあり、読めませんでした」と出ます。カンマや " の数を見直してください。

画面の見本を使わずに、お題の欄に直接書いても走らせられます。記録には「お題の名前」の欄に書いた名前で残ります。

プロンプト集

プロンプト集 のフォルダに、画面の見本と同じ7本のお題を文字だけで入れてあります。ほかの AI の画面に貼って試すときに使えます。

  1. 売上の表 → 1枚のダッシュボード（正しい数字：10か月の合計 9,999,000円・前月比 +7.6%・いちばん伸びたのは布もの +129.5%）
  2. 提案書を1枚で
  3. 社内に配る800字の記事
  4. 間取り図の画像 → 歩ける3Dの家（見本の間取り図.png を添えて使います）
  5. 1枚の HTML で動く小さなゲーム
  6. 長い規約から大事な所を表に（規約は架空のものです。数字の写し違いがないかを見ます）
  7. お試し：短い3問で速さと正しさ（正しい答え：2,926円・2027年2月25日）

注意

  • AI の答えは、まちがえることがあります。数字・寸法・規約の読み取りなど、大事な判断に使う前に、必ず自分で確かめてください。
  • 同じお題・同じモデルでも、走らせるたびに答えや時間は変わります。1回だけで決めず、何回か走らせて記録を見くらべるのがおすすめです。
  • かかった時間は、そのときの混み具合や、OpenRouter がどの提供元につないだかでも変わります（提供元は結果の列と記録に出ます）。

プロンプト集/5_1枚のHTMLで動く小さなゲーム.txt

- 上から落ちてくる「りんご」を、画面の下のかごで受け止める

- いちばん良いスコアは、画面を開いている間だけ覚えておく（保存の仕組みは使わない）

- 1つの HTML ファイルで完結（外部のライブラリ・画像・音・フォントを読み込まない。絵は Canvas で自分で描く）
- 画面の文字は日本語。画面の幅が変わっても遊べる
- 出力は HTML だけ（説明の文は要らない）
