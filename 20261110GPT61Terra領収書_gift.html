領収書仕分けキット（GPT-6.1 Terra × Codex CLI）

月末に領収書を 1 枚ずつ見て、日付・お店・金額・消費税を表に打ち込む（手入力は 1 枚 90 秒〜2 分・手書き 2〜4 分という目安）→ 写真を受け取り箱に入れて 1 行打つと、名前の付け直し・月のフォルダ分け・経費一覧（CSV）まで済む。税の計算が合わない物は要確認に分かれる

非エンジニアの業務 向け
領収書仕分けキット.zip をダウンロード

12 ファイル・452 KB。スマホで開いたときは、パソコンで開き直してからダウンロードしてください。

受け取り箱/ に領収書・レシートの写真を入れて 1 行打つと、GPT-6.1 Terra が読み取って次の 3 つをやります。

  1. 写真の名前を 日付_勘定科目_支払先_金額円.jpg に付け直す
  2. 月ごとのフォルダ（仕分け済み/2026-10/ など）へ分ける
  3. Excel でそのまま開ける経費一覧（経費一覧_2026-10.csv）を作る

読めない所・税の計算が合わない物は、推測で埋めずに 仕分け済み/要確認/ へ分けます。元の写真は消さずに 受け取り箱/_済み/ へ移すだけです。

入れ方（3 手）

  3. brew install --cask codex
  4. ターミナルで codex と打ち、「Sign in with ChatGPT」でログインする（Terra を使えるのは ChatGPT の Plus・Pro・Business など有料のプラン）
  5. このフォルダを好きな場所に置き、ターミナルでそのフォルダへ移って、まず見本で試す

--dry-run は読むだけで、ファイルは動かしません。結果が画面に出たら、自分の写真を 受け取り箱/ に入れて本番です。

python3 sort_receipts.py

自分のルールを教える（設定.json）

欄中身
model読み取りに使うモデル（既定 gpt-6.1-terra）
effort考える深さ（既定 medium。手書きが多いなら high）
accounts選ばせる勘定科目の一覧
my_rules自分の経費のルールを文で（例「タクシー・電車・駐車場は旅費交通費」）

ルールに無い・決めきれない物は「要確認」に分かれます。ルールを足すほど、要確認が減ります。

気をつけること

  • 最後は自分の目で確かめる: 要確認に分かれなかった物も、月に 1 回は経費一覧と写真を見比べてください。AI の読み取りは間違えることがあります。
  • 税務の判断は税理士や国税庁で: このキットは整理の道具です。これだけで電子帳簿保存法の保存の要件（タイムスタンプ・訂正や削除の記録など）を満たすものではありません。紙の原本の扱い、登録番号が本物かどうかの確認も別の作業です。
  • 写真は OpenAI に送られます: 個人のプラン（Plus・Pro）は、ChatGPT の「設定 → データコントロール → すべての人のためにモデルを改善する」をオフにしておくと安心です。Codex の設定にも別の項目があります。会社の領収書は、会社の決まりを先に確かめてください。
  • Windows では、公式の案内（Windows と WSL のページ）に沿って Codex CLI を入れてください。動作を確かめたのは Mac です。

sort_receipts.py

#!/usr/bin/env python3
"""領収書仕分けキット — 受け取り箱に入れた領収書の写真を GPT-6.1 Terra に読ませて、
名前を付け直し・月ごとのフォルダへ分け・経費一覧（CSV）を作る。

使い方:
  python3 sort_receipts.py                 # 受け取り箱/ の写真を仕分ける
  python3 sort_receipts.py --dry-run       # 読むだけ。ファイルは動かさない（結果は画面に出す）
  python3 sort_receipts.py --inbox <フォルダ> --out <フォルダ>

必要なもの: Codex CLI（ChatGPT の Plus 以上でログイン済み）と Python 3.9 以上。追加のライブラリは要らない。
読み取りは Codex CLI の `codex exec` に任せる（ChatGPT の枠で動く＝API キーは要らない）。

元の写真は消さない: 仕分けた写しを 仕分け済み/ に作り、元は 受け取り箱/_済み/ へ移す。
税の計算が合わない・読めない所がある物は 仕分け済み/要確認/ に入れる（推測で埋めない）。
"""
import argparse
import csv
import datetime
import json
import re
import shutil
import subprocess
import sys
import tempfile
import time
from pathlib import Path

HERE = Path(__file__).resolve().parent
IMAGE_EXT = {".jpg", ".jpeg", ".png", ".webp", ".heic", ".heif"}
CONVERT_EXT = {".heic", ".heif"}   # iPhone の標準の形式。Codex はそのまま読めない＝ Mac の sips で JPEG にしてから渡す
BATCH = 8          # 1回の呼び出しで読ませる枚数（多すぎると取り違えが増える）
CHECK = "要確認"

SCHEMA = {
    "type": "object",
    "additionalProperties": False,
    "required": ["items"],
    "properties": {
        "items": {
            "type": "array",
            "items": {
                "type": "object",
                "additionalProperties": False,
                "required": ["file", "date", "payee", "item", "total", "tax",
                             "rate", "tax8", "tax10", "account", "invoice_no", "doubt"],
                "properties": {
                    "file": {"type": "string"},
                    "date": {"type": "string"},
                    "payee": {"type": "string"},
                    "item": {"type": "string"},
                    "total": {"type": ["integer", "null"]},
                    "tax": {"type": ["integer", "null"]},
                    "rate": {"type": "string", "enum": ["8%", "10%", "混在", "不明"]},
                    "tax8": {"type": ["integer", "null"]},
                    "tax10": {"type": ["integer", "null"]},
                    "account": {"type": "string"},
                    "invoice_no": {"type": "string"},
                    "doubt": {"type": "string"},
                },
            },
        }
    },
}


def load_settings(path):
    s = json.loads(Path(path).read_text(encoding="utf-8"))
    s.setdefault("model", "gpt-6.1-terra")
    s.setdefault("effort", "medium")
    s.setdefault("accounts", ["会議費", "旅費交通費", "消耗品費", "新聞図書費", "福利厚生費"])
    s.setdefault("my_rules", [])
    return s


def build_prompt(files, s):
    names = "\n".join("%d. %s" % (i + 1, f.name) for i, f in enumerate(files))
    rules = "\n".join("- " + r for r in s["my_rules"]) or "- （なし）"
    return f"""添付した{len(files)}枚の領収書・レシートの写真を読み取って、経費の記録を作ってください。
写真は次の順に添付しています。file にはこの名前をそのまま入れてください。
{names}

項目の決まり:
- date: 発行日を YYYY-MM-DD で。読めなければ「{CHECK}」
- payee: 支払先（お店・会社の名前）。支店名があれば付ける
- item: 何を買ったか・何の代金かを短く
- total: 税込の支払金額（円・整数）。お預かり・お釣りと取り違えない。読めなければ null
- tax: うち消費税の合計（円・整数）。書いていなければ null
- rate: 「8%」「10%」「混在」「不明」のどれか
- tax8 / tax10: 混在のときだけ税率ごとの消費税（円）。それ以外は null
- account: 勘定科目を次から1つ選ぶ: {"・".join(s["accounts"])}。決めきれなければ「{CHECK}」
- invoice_no: 適格請求書の登録番号（T から始まる番号）が書いてあれば写す。無ければ空文字
- doubt: 日付・支払先・金額・消費税・勘定科目のうち、自信がない所・読めなかった所を短く。全部読めたら空文字
  （登録番号が本物かどうかは判定しない＝国税庁の公表サイトで別に確かめる作業）

自分の経費のルール（勘定科目を選ぶときに守る）:
{rules}

推測で埋めないこと。読めない・自信がない所は「{CHECK}」か null にして、doubt に理由を書く。"""


def readable(f, td):
    """Codex が読める形の道筋を返す。HEIC は JPEG の写しを作る（元のファイルはそのまま）。"""
    if f.suffix.lower() not in CONVERT_EXT:
        return f
    if not shutil.which("sips"):
        raise RuntimeError("HEIC の写真（%s）を JPEG にできません（sips は Mac だけ）。JPEG で撮り直すか書き出してください。" % f.name)
    out = td / (f.stem + "_heic.jpg")
    subprocess.run(["sips", "-s", "format", "jpeg", str(f), "--out", str(out)],
                   capture_output=True, check=True)
    return out


def read_batch(files, s, log):
    """codex exec に画像をまとめて渡し、決まった形の JSON で受け取る。"""
    with tempfile.TemporaryDirectory() as td:
        schema = Path(td) / "schema.json"
        out = Path(td) / "out.json"
        schema.write_text(json.dumps(SCHEMA, ensure_ascii=False), encoding="utf-8")
        cmd = ["codex", "exec", "-m", s["model"], "-c", "model_reasoning_effort=%s" % s["effort"],
               "-s", "read-only", "--skip-git-repo-check", "--ephemeral",
               "--output-schema", str(schema), "-o", str(out)]
        for f in files:
            cmd += ["-i", str(readable(f, Path(td)))]
        t0 = time.time()
        # プロンプトは標準入力で渡す（-i の後ろに書くと画像の名前として読まれる）
        r = subprocess.run(cmd, input=build_prompt(files, s), capture_output=True, text=True)
        sec = time.time() - t0
        log.write("--- %s %s %.1fs rc=%d\n%s\n" % (datetime.datetime.now().isoformat(timespec="seconds"),
                                                  s["model"], sec, r.returncode, r.stderr[-2000:]))
        if r.returncode != 0 or not out.exists():
            raise RuntimeError("Codex の読み取りに失敗しました（rc=%d）。ログ: _log.txt" % r.returncode)
        data = json.loads(out.read_text(encoding="utf-8"))
    return data["items"], sec


def expected_tax(total, rate):
    if total is None:
        return None
    pct = {"8%": 8, "10%": 10}.get(rate)
    return None if pct is None else total * pct // (100 + pct)


def checks(it):
    """機械の検算。合わない物は要確認へ回す（AI の読み取りを信じ切らない）。"""
    why = []
    if not re.fullmatch(r"\d{4}-\d{2}-\d{2}", it["date"] or ""):
        why.append("日付が読めない")
    if it["total"] is None:
        why.append("金額が読めない")
    if it["account"] == CHECK:
        why.append("勘定科目を決めきれない")
    exp = expected_tax(it["total"], it["rate"])
    if exp is not None and it["tax"] is not None and abs(exp - it["tax"]) > 1:
        why.append("消費税が合わない（%s なら約%d円・読み取り%d円）" % (it["rate"], exp, it["tax"]))
    if it["rate"] == "混在" and None not in (it["tax"], it["tax8"], it["tax10"]) \
            and it["tax8"] + it["tax10"] != it["tax"]:
        why.append("税率ごとの消費税の合計が合わない")
    if it["doubt"]:
        why.append("AI のメモ: " + it["doubt"])
    return why


def safe(name):
    name = re.sub(r"[\\/:*?\"<>|\s]+", "", name or "")
    return name[:30] or "不明"


def main():
    ap = argparse.ArgumentParser(description=__doc__.splitlines()[0])
    ap.add_argument("--inbox", default=str(HERE / "受け取り箱"))
    ap.add_argument("--out", default=str(HERE / "仕分け済み"))
    ap.add_argument("--settings", default=str(HERE / "設定.json"))
    ap.add_argument("--dry-run", action="store_true")
    a = ap.parse_args()

    if not shutil.which("codex"):
        sys.exit("Codex CLI が見つかりません。README の「入れ方」を見てください。")
    s = load_settings(a.settings)
    inbox, out = Path(a.inbox), Path(a.out)
    inbox.mkdir(parents=True, exist_ok=True)
    files = sorted(p for p in inbox.iterdir() if p.suffix.lower() in IMAGE_EXT)
    if not files:
        sys.exit("受け取り箱に写真がありません: %s" % inbox)

    out.mkdir(parents=True, exist_ok=True)
    rows, total_sec = [], 0.0
    with open(out / "_log.txt", "a", encoding="utf-8") as log:
        for i in range(0, len(files), BATCH):
            chunk = files[i:i + BATCH]
            print("読み取り中: %d〜%d枚目 / %d枚（%s）" % (i + 1, i + len(chunk), len(files), s["model"]))
            items, sec = read_batch(chunk, s, log)
            total_sec += sec
            by_name = {it["file"]: it for it in items}
            for f in chunk:
                it = by_name.get(f.name)
                if it is None:   # AI が file 名を書き換えた・飛ばした
                    it = {k: None for k in SCHEMA["properties"]["items"]["items"]["required"]}
                    it.update(file=f.name, date=CHECK, payee="", item="", rate="不明",
                              account=CHECK, invoice_no="", doubt="この写真の結果が返ってこなかった")
                rows.append((f, it, checks(it)))

    ok = sum(1 for _, _, w in rows if not w)
    print("\n読み取り %.0f秒・%d枚（そのまま使える %d枚／要確認 %d枚）\n" % (total_sec, len(rows), ok, len(rows) - ok))
    for f, it, why in rows:
        mark = "要確認" if why else "OK"
        print("[%s] %s → %s %s %s円（税%s円・%s）%s" % (
            mark, f.name, it["date"], it["payee"], it["total"], it["tax"], it["account"],
            ("  ← " + "／".join(why)) if why else ""))
    if a.dry_run:
        print("\n--dry-run のため、ファイルは動かしていません。")
        return

    done = inbox / "_済み"
    done.mkdir(exist_ok=True)
    by_month = {}
    for f, it, why in rows:
        if why:
            dest_dir = out / CHECK
        else:
            dest_dir = out / it["date"][:7]
        dest_dir.mkdir(parents=True, exist_ok=True)
        stem = "%s_%s_%s_%s円" % (it["date"] if not why or re.fullmatch(r"\d{4}-\d{2}-\d{2}", it["date"] or "") else "日付不明",
                                 safe(it["account"]), safe(it["payee"]), it["total"] if it["total"] is not None else "不明")
        dest = dest_dir / (stem + f.suffix.lower())
        n = 2
        while dest.exists():
            dest = dest_dir / ("%s_%d%s" % (stem, n, f.suffix.lower()))
            n += 1
        shutil.copy2(f, dest)
        shutil.move(str(f), str(done / f.name))
        key = CHECK if why else it["date"][:7]
        by_month.setdefault(key, []).append((dest, it, why))

    for key, items in by_month.items():
        csv_path = out / ("経費一覧_%s.csv" % key)
        new = not csv_path.exists()
        with open(csv_path, "a", newline="", encoding="utf-8-sig") as fp:   # Excel で文字化けしない形
            w = csv.writer(fp)
            if new:
                w.writerow(["日付", "支払先", "内容", "税込金額", "うち消費税", "税率", "8%の税", "10%の税",
                            "勘定科目", "登録番号", "要確認の理由", "ファイル"])
            for dest, it, why in items:
                w.writerow([it["date"], it["payee"], it["item"], it["total"], it["tax"], it["rate"],
                            it["tax8"], it["tax10"], it["account"], it["invoice_no"], "／".join(why), dest.name])
        print("書きました: %s（%d件）" % (csv_path, len(items)))
    print("元の写真は %s に移しました（消していません）。" % done)


if __name__ == "__main__":
    main()
